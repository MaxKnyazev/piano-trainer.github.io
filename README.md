# Такт — личная школа пианино

Статическое приложение на React + TypeScript + Vite. UI построен на Radix Primitives, иконки Lucide. Без бэкенда, аккаунтов и серверной базы данных. Размещение — GitHub Pages или любой статический хостинг.

## Запуск

Требуется Node.js 22 и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://127.0.0.1:5173).

```sh
npm test         # музыкальные расчёты и формат резервной копии
npm run build   # TypeScript и production-сборка в dist/
npm run preview # локальная проверка production-сборки
```

Браузерные проверки:

```sh
npx playwright install chromium
npm run test:e2e
npm run test:production # после npm run build: проверка сборки в подпапке /piano-trainer/
```

Если Chromium уже установлен в другом месте, задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` — полный путь к исполняемому файлу. Тесты самостоятельно запускают и останавливают Vite на порту 4173.

## GitHub Pages

1. Создайте GitHub-репозиторий и загрузите исходники в ветку `main`. Не загружайте `node_modules`, `.npm-cache` или `dist`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` при push в `main` проверит проект, соберёт его и опубликует папку `dist`. Его можно запустить вручную во вкладке Actions.
4. Ссылка появится в результате job `deploy` и в Settings → Pages.

Приложение использует `HashRouter` и относительный `base: './'`. Поэтому адреса вида `https://username.github.io/piano-trainer/#/course/keyboard` работают при прямом открытии и перезагрузке. Подходит и для домена `username.github.io`, и для собственного домена. При другой основной ветке измените `branches` в workflow.

Инструкция по сборке и публикации соответствует [руководству Vite](https://vite.dev/guide/static-deploy.html#github-pages).

## Что работает

- План на 15, 30 или 45 минут и переход к следующей незавершённой главе.
- 18 глав с развёрнутыми объяснениями, пошаговыми примерами, разбором трудностей и вопросами для самопроверки. 108 упражнений трёх уровней; отметки выполнения и прогресс.
- Чтение нот в двух ключах с тремя диапазонами, ответы на экране или по MIDI.
- Ритмическая тренировка: девять нажатий, оценка восьми событий относительно сетки от первого нажатия.
- Слух: распознавание пяти восходящих интервалов от разных исходных нот.
- Построение мажорных и минорных трезвучий.
- Ровность: восьмизвучная последовательность с раздельной оценкой правильности нот и времени.
- Простой редактор мелодии до 32 нот, четыре длительности, воспроизведение, экспорт MusicXML и сохранение в библиотеку.
- Звуковой метроном с акцентом на первую долю, 30–200 BPM.
- Библиотека PDF, PNG/JPG/WebP и несжатого MusicXML; просмотр, заметки, этап изучения, скачивание оригинала и подтверждаемое удаление.
- Экспорт и восстановление полной резервной копии с проверкой формата и подтверждением замены.
- Адаптивный интерфейс, клавиатурный фокус, диалоги и вкладки Radix.

## Локальное хранение

Все пользовательские данные записываются в **localStorage**, ключ `takt-piano:v1`. Файлы включаются в сохранение: изображения и PDF как data URL, MusicXML как текст. IndexedDB и внешняя база не используются. Уроки входят в исходники приложения.

Ограничение загрузки — **1 МБ на файл**. Общая квота localStorage зависит от браузера; код обрабатывает отказ записи и не применяет изменение, которое не удалось сохранить. Для крупных сборников можно создать карточку без вложения и хранить оригинал отдельно. Эта версия рассчитана на небольшую личную библиотеку.

В **Настройки и данные → Экспортировать всё** скачивается JSON, включающий прогресс, последние 500 результатов тренажёров, библиотеку с файлами, черновик и настройки. Для переноса на другое устройство импортируйте этот файл и подтвердите замену. Файл резервной копии должен быть не больше 8 МБ.

Хранение привязано к origin браузера. Переход с localhost на GitHub Pages, на другой домен или в другой профиль браузера требует ручного переноса. Репозитории GitHub Pages одного аккаунта на одном домене разделяют origin и этот ключ. Очистка данных сайта удаляет сохранение. Приватный режим не гарантирует сохранение после закрытия окна.

Шрифт поставляется локально через Fontsource. Ноты и прогресс не отправляются приложением на сервер. GitHub Pages обслуживает статические файлы; это не облачная синхронизация пользовательских данных.

## Подключение Tesler STZ-8825

1. Подключите USB-MIDI инструмента к компьютеру подходящим кабелем.
2. Откройте тренажёр чтения нот, аккордов или ровности.
3. Нажмите **USB-MIDI**, разрешите доступ и проверьте название устройства.

Используется Web MIDI API без SysEx. Для размещённого сайта требуется HTTPS; localhost подходит для разработки. Поддержку проверяйте в браузере, прежде всего в актуальном Chrome/Edge на компьютере. При отказе доступа остаётся экранная клавиатура. Подключение, отключение и повторное подключение устройств отслеживаются. Аппаратная совместимость и передача педалей требуют проверки на реальном инструменте.

## Границы первой версии

Курс содержит 18 глав: в каждой есть вступление, четыре раздела объяснений, разобранный пример, две типичные трудности с решениями, два вопроса с раскрываемыми ответами и план занятий. Практика расширена с трёх до шести упражнений на главу. Три новых задания содержат цель и упрощённый вариант. Первые три задания сохраняют свои прежние индексы, поэтому старые отметки и резервные копии совместимы. Процент прогресса может стать меньше из-за добавления новых заданий. Следующее развитие — наглядные демонстрации и учебные пьесы.

Отметки упражнений курса — самооценка. MIDI автоматически проверяет только отдельные тренажёры. Оценка произвольной импортированной пьесы, определение рук, педализации, артикуляции или техники движений не реализованы. Микрофон не используется. Нет записи аудио, автоматического распознавания PDF, импорта MIDI/MXL или облачной синхронизации.

Звук тренажёров — простой синтезированный тембр. Редактор сохраняет свободную последовательность нот без тактового размера, пауз, альтераций и полифонии. Это эскиз для первых упражнений, не полноценный нотный редактор.

Нотный просмотр MusicXML использует [OpenSheetMusicDisplay](https://github.com/opensheetmusicdisplay/opensheetmusicdisplay); эта библиотека загружается отдельным большим JS-файлом только при открытии соответствующего произведения. Ритмическая оценка использует учебный допуск 15% доли, максимум 120 мс; задержки устройства и браузера пока не калибруются. Отображаемый темп упражнения — заданный пользователем, а не автоматически установленный «устойчивый темп».

## Структура

- `src/course.ts` — исходные главы и сборка курса с совместимыми идентификаторами упражнений.
- `src/course-expansion.ts` — развёрнутые объяснения, примеры, самопроверка и дополнительные задания всех 18 глав.
- `src/Lesson.tsx` — чтение главы, навигация, фильтр сложности и практика.
- `src/App.tsx` — страницы курса, план, прогресс и настройки.
- `src/Trainers.tsx` — тренажёры и редактор.
- `src/Library.tsx` — файлы и просмотр нот.
- `src/components.tsx` — нотный стан, клавиатура, метроном и MIDI.
- `src/music.ts` — высота нот, аккорды, время и синтез звука.
- `src/storage.ts` — формат данных, валидация, загрузка и экспорт.
- `e2e/` — браузерные сценарии основных пользовательских действий.
